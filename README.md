# devTinder 🚀

devTinder is a developer networking platform inspired by Tinder, where developers can connect, collaborate, and build meaningful professional relationships.

The application allows users to create profiles, explore other developers, send connection requests, and interact in a modern and intuitive interface.

## ✨ Features

* 🔐 User Authentication & Authorization
* 👤 Developer Profile Creation
* ❤️ Like / Ignore Developer Profiles
* 🤝 Connection Requests
* 💬 Real-time Chat Support
* 📱 Responsive UI for Mobile & Desktop
* ⚡ Fast and scalable backend APIs
* 🛡️ Secure password hashing & authentication

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Redux Toolkit

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication
* Socket.IO

## 🎯 Goal

The main goal of devTinder is to help developers discover like-minded people, expand their professional network, collaborate on projects, and grow together in the tech community.
